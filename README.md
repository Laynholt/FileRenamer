# FileRenamer

`FileRenamer` — desktop-приложение на **C++20 + WinAPI** для массового переименования файлов и папок по шаблону.

## Скриншоты

![Главное окно FileRenamer](screenshots/main.png)

## Возможности

- Переименование по обычной строке поиска.
- Переименование по `regex` (опционально).
- Опция `Игнорировать регистр` для обычного поиска и regex.
- Поддержка **файлов и папок**.
- Кнопка `Справка` с меню:
  - `Горячие клавиши`
  - `О программе`
- Проверка и установка обновлений из окна `О программе`.
- Кастомные диалоговые окна сообщений в стиле приложения.
- Режимы при пустом поле `Паттерн`:
  - `<text` — добавить `text` в начало имени.
  - `>text` — добавить `text` в конец имени (для файлов перед расширением, для папок в конец имени).
- Двухфазное безопасное переименование (через временные имена) с откатом при ошибке.
- Предпросмотр до лимита (`PREVIEW_LIMIT`) с указанием скрытых элементов.
- Автоподстановка активного пути из Проводника Windows.

### Горячие клавиши

- `Ctrl+Space` в `Паттерне` или `Шаблоне замены` — открыть подсказки (также доступны кнопки рядом с полями).
- В открытых подсказках: `↑` / `↓` — выбрать вариант, `Enter` или двойной щелчок — применить, `Esc` — закрыть. `Enter` при выборе подсказки не запускает переименование.

- `Tab` — открыть выбор папки (`Обзор...`).
- `Enter` — запустить переименование.
- Любая буква/цифра (кириллица/латиница), если фокус не в поле ввода — переводит фокус в `Паттерн` и вводит символ туда.
- `Down` в поле `Паттерн` — переход в `Шаблон замены`.
- `Up` в поле `Шаблон замены` — переход в `Паттерн`.
- `Esc` в полях ввода — снять фокус на главное окно.

## Подсказки regex и нумерация

Включите `Использовать regex` и откройте подсказки у поля `Паттерн`. Приложение анализирует имена в выбранной папке локально, без сети. Доступны сезоны/серии (`S02E03`, `2x03`), номера в конце имени, общие структуры с числовыми частями, удаление квадратных скобок и начальных номеров, замена разделителей.

Каждый вариант показывает число совпадений, объяснение, паттерн, замену, пример результата и пример неподходящего имени. Выбор заполняет **оба поля** и обновляет предпросмотр. Если замена содержит слово `Название`, оно выделяется — введите своё название. Это эвристические предложения; окончательный результат проверяйте в предпросмотре.

Подсказки у поля замены вставляют токен в позицию курсора или вместо выделения. При вводе `$` или `{n:` список фильтруется, а выбор дополняет начатый токен. Для выбранного готового паттерна группы подписаны по смыслу (сезон, серия, расширение); для своего regex показываются номера групп и пример их содержимого.

| Шаблон | Значение |
|---|---|
| `Название {n}` | Новая нумерация: `Название 1`, `Название 2`… |
| `Название {n:03}` | Нумерация с ведущими нулями: `Название 001`, `Название 002`… |
| `$1`, `$2`… | Текст из соответствующей группы regex, **не счётчик** |
| `$&` | Всё совпадение regex |
| `$$` | Буквальный знак `$` в режиме regex |

Счётчик доступен и без regex. Он начинается с 1, учитывает только подходящие элементы и следует естественной сортировке предпросмотра. Все вхождения `{n}` в одном имени получают один номер. Формат `{n:0N}` задаёт минимальную ширину от 1 до 32 цифр; номер не обрезается при превышении ширины. Нераспознанные формы остаются обычным текстом.

При **пустом паттерне** замена с `{n}` целиком задаёт новое имя, сохраняя расширение файла. Для папок заменяется всё имя. Режимы `<` и `>` также поддерживают счётчик: `<{n}-` добавляет номер в начало, `>-{n:02}` — в конец перед расширением. При **непустом паттерне** заменяется только найденный фрагмент; если regex захватывает расширение, сохраните его соответствующей группой в замене.

Предпросмотр ограничен 400 строками; подбор показывает число совпадений по всей папке. Для вывода общих структур рассматриваются до 128 первых имён и 16 различных кандидатов. Фактическое переименование использует ту же нумерацию и существующую проверку конфликтов имён.

## Обновления

### v1.1.0

- Добавлены локальные подсказки regex и шаблонов замены: `Ctrl+Space` или кнопки рядом с полями, примеры результата, число совпадений и пояснения групп.
- Добавлена нумерация `{n}` и `{n:03}` с естественным порядком файлов; она работает в обычной замене, regex, префиксах и суффиксах.
- Выбор подсказки заполняет поля и обновляет предпросмотр; `Enter` в списке применяет подсказку, не запуская переименование.
- Подключена библиотека `win32-custom-widgets` для тёмной прокрутки подсказок; сборка переведена на C++20.
- Исправлен порядок COM-заголовков для актуального Windows SDK. Сборка Release x64 проверена с Build Tools 2026; для запуска нужен Visual C++ Redistributable x64.
- Добавлены тесты нумерации, подсказок и их взаимодействия с интерфейсом.

- Проверка обновлений запускается через `Справка` -> `О программе` -> `Проверить обновления`.
- Для автообновления используется GitHub Releases репозитория `Laynholt/FileRenamer`.

## Сборка

### Требования

- Windows 10/11
- CMake 4.2+ для генератора Visual Studio 2026
- C++20-совместимый компилятор
- Microsoft Build Tools 2026 с компонентами C++ (MSVC v145) и Windows SDK; IDE Visual Studio необязательна
- Исходники `win32-custom-widgets` в соседней папке (или путь через `-DWCW_SOURCE_DIR=...`). Библиотека статически встраивается в приложение и предоставляет тёмную прокрутку подсказок, видимую только при переполнении.

### Команды

```powershell
cmake -S . -B build -G "Visual Studio 18 2026" -A x64 -T v145 -DBUILD_TESTING=ON -DWCW_BUILD_DEMO=OFF
cmake --build build --config Release --parallel 2
ctest --test-dir build -C Release --output-on-failure
```

Готовый бинарник:

- `build/bin/Release/FileRenamer.exe`

Проверена сборка Release x64: MSVC 19.51.36260, Windows SDK 10.0.26100.0. При переходе с другой версии Visual Studio выполните команду конфигурации с `--fresh`: CMake пересоздаст только свой кеш и `CMakeFiles` в существующей папке `build`.

Для запуска этой сборки с динамическим CRT (`/MD`) установите актуальный [Microsoft Visual C++ Redistributable x64](https://aka.ms/vc14/vc_redist.x64.exe). Статическое встраивание `win32-custom-widgets` не отменяет зависимость приложения от CRT.

## Использование

1. Выберите папку.
2. Заполните `Паттерн` и `Шаблон замены`.
3. При необходимости включите `regex` и/или `Игнорировать регистр`.
4. Проверьте предпросмотр.
5. Нажмите `Переименовать`.
6. При необходимости откройте `Справка` для горячих клавиш, информации о версии и обновлений.
